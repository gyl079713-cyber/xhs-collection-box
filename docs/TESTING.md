# 发布前测试清单

每个准备公开发布的版本至少执行一次基础检查，并在真实 Chrome 中完成核心流程。

## 自动检查

需要 Node.js 18 或更高版本：

```bash
npm run check
```

## 安装与更新

- [ ] 在 Chrome 114+ 中通过“加载已解压的扩展程序”安装成功。
- [ ] 工具栏图标显示正确，点击后打开侧边栏。
- [ ] 覆盖原文件并刷新扩展后，本地数据仍然存在。
- [ ] 清洁 Chrome 用户资料中的首次安装不会出现示例或他人数据。

## 收藏盲盒

- [ ] 至少准备 25 条索引，连续拆三批，每批最多十条且同一轮无重复。
- [ ] 全部出现后显示“重新洗牌”。
- [ ] 关闭并重新打开侧边栏后，当前批次和本轮进度保留。
- [ ] 点击两个不同标题时复用同一个阅读标签页。
- [ ] 点击 `×` 只从本地盲盒移出，恢复后可再次抽到。

## 划线与 Notes

- [ ] 在原笔记正文选中文字后出现「Note」按钮。
- [ ] 保存后原文显示高亮，刷新页面后高亮可以恢复。
- [ ] 点击高亮可以新增或修改 Note。
- [ ] 整篇 Note 可以创建、编辑和删除。
- [ ] Notes 页面可返回原笔记并导出 Markdown。
- [ ] 评论区和图片文字不会错误地显示为已支持划线。

## 采集

- [ ] 只有在自己的小红书个人主页收藏标签中才能启动。
- [ ] 开始后进度持续更新，重复笔记按 ID 去重。
- [ ] 点击停止后，已读取数据保留。
- [ ] 达到约 500 条或 100 次滚动的单批保护上限后自动停止，已读取数据保留，5 分钟内不能再次启动。
- [ ] 页面出现登录失效提示时自动停止，并提示重新登录。
- [ ] 页面出现安全验证或访问异常提示时自动停止，30 分钟内不能再次启动。
- [ ] 关闭侧边栏但保留收藏页时，后台缓存继续保存。
- [ ] 页面出现安全提示时立即停止，不继续压力测试。

## 备份与恢复

- [ ] 完整 JSON 可以导出。
- [ ] JSON 和 Markdown 导出的链接不包含 `xsec_token` 或 `xsec_source`。
- [ ] 在空白环境导入后，收藏索引、盲盒进度和 Notes 恢复。
- [ ] 导入已有环境时按 ID 合并，不覆盖当前同 ID 记录。
- [ ] Markdown 导出不包含不可用的本地文件路径。

## 视觉检查

分别检查 macOS 与 Windows、浅色与深色模式：

- [ ] 320–500 px 侧边栏宽度下没有横向滚动条。
- [ ] 中文标题、长英文标题和 Notes 数量不会挤压操作按钮。
- [ ] `COLLECTION ATLAS｜收藏观察` 保持单行。
- [ ] 第十条与下方分隔线的间距和其他列表分隔一致。
- [ ] 系统缩放 100%、125% 和 150% 下主要按钮仍可点击。
