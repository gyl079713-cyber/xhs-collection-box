# 收藏观察｜小红书收藏盲盒

简体中文 | [English](README.en.md)

一个用于重新遇见小红书旧收藏的 Chrome 侧边栏扩展。它从已建立的收藏索引中，每次随机展示最多十条；打开原笔记后，可以保存正文划线和自己的 Note。

当前版本：**0.7.3**  
运行环境：**Chrome 114+**  

> [!WARNING]
> 本项目仅供学习与个人数据管理使用。使用自动采集、滚动等功能操作平台账号，可能触发限流、安全验证、功能限制甚至账号封禁。请遵守平台规则，仅处理自己有权访问的数据，并自行承担使用风险。在适用法律允许的范围内，作者不对账号处罚、功能受限、数据丢失或其他相关损失负责。

## 为什么做它

收藏多了以后，逐条分类本身也会变成压力。收藏观察不要求用户先整理几千条内容，而是每次给出一小批随机入口：愿意重看的就打开，有价值的就留下划线或 Note，不再需要的可以从本地盲盒移出。

插件没有 AI 分类、每日目标、完成率或连续使用提醒。

## 主要功能

- **收藏盲盒：**每批随机展示最多十条标题；同一轮不重复，全部出现后可以重新洗牌。
- **原文阅读：**点击不同标题时复用同一个阅读标签页，避免不断打开新标签。
- **本地整理：**右侧 `×` 只把记录从本地盲盒移出，不会替用户取消小红书收藏；误操作可以恢复。
- **划线与 Note：**在原笔记可选中的正文上保存划线，之后点击高亮补写或修改 Note；也可以给整篇笔记写 Note。
- **数据备份：**可导出 Markdown，也可用完整 JSON 备份和恢复收藏索引、盲盒进度及 Notes。
- **按需采集：**在自己的收藏页主动启动辅助采集；支持停止、去重，并保留中途已经读取的数据。

## 安装

1. 从 GitHub Releases 下载 ZIP，并完整解压。
2. 在 Chrome 打开 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择解压后的 `xhs-collection-box` 文件夹；不要直接选择 ZIP。
6. 建议把工具栏里的珊瑚红盲盒图标固定起来。

Chrome 官方的本地扩展安装方式可参考 [Load an unpacked extension](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 开始使用

### 1. 建立收藏索引

登录小红书网页版，打开**自己的个人主页 → 收藏**，再在侧边栏的「补充收藏数据」区域点击「开始采集」。收藏页必须保持打开。

不必为了第一次体验就扫描全部收藏。停止后，已读取的数据会保留；之后重复采集时会按笔记 ID 去重。

为减少持续自动访问，单次采集最多读取约 500 条或滚动 100 次，并适当放慢滚动间隔。达到保护上限后，已读取的数据会保留，并进入 5 分钟冷却。插件检测到登录失效、安全验证或访问异常提示时会立即停止；安全异常后至少冷却 30 分钟。

> [!CAUTION]
> 连续加载大量收藏可能触发小红书账号安全限制。插件不能保证大规模采集不会触发平台风控；出现异常提示时应立即停止。

### 2. 拆收藏盲盒

点击刷新图标随机换一批。同一轮内，出现过的记录不会再次抽到；`本轮已出现 N / M` 只表示标题进入过盲盒，不表示已经读完。

点击标题进入原笔记。右侧 `×` 只影响插件本地随机池，不会操作原站收藏状态。

### 3. 保存划线与 Note

在原笔记中选中可选取的正文，点击浮窗里的「Note」保存划线；之后点击高亮可以补写自己的想法。图片中的文字和评论区目前不支持划线，可以改为给整篇笔记写 Note。

## 数据与隐私

收藏索引、盲盒进度、移出记录、划线和 Notes 保存在当前 Chrome 用户资料的 `chrome.storage.local` 中。插件不包含云同步、遥测、广告或第三方 AI 请求。

- 换电脑或换 Chrome 用户资料时，数据不会自动出现。
- 移除扩展会清除其本地数据。
- 更新或重新安装前，建议先导出完整 JSON 备份。
- 当前版本导出 JSON 和 Markdown 时会自动移除笔记链接中的 `xsec_token`、`xsec_source`；备份仍包含私人收藏、摘录和 Notes，不要提交到公开仓库或发送给他人。
- 完整的数据处理说明见 [PRIVACY.md](PRIVACY.md)。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 在 Chrome 侧边栏显示盲盒与 Notes。 |
| `storage` | 在本地保存收藏索引、盲盒状态和 Notes。 |
| `tabs` | 打开或复用小红书笔记标签页。 |
| `scripting` | 用户主动采集时向当前小红书页面注入采集脚本。 |
| `activeTab` | 识别用户当前操作的小红书标签页。 |
| `https://www.xiaohongshu.com/*` | 在小红书收藏页读取用户已加载的收藏，并在笔记页提供划线功能。 |

## 已知边界

- 小红书网页版收藏列表目前没有提供可靠的逐条收藏日期，因此插件不展示历史收藏月历。
- 采集依赖打开的收藏页正常加载，不能脱离页面在后台瞬间读完全部历史收藏。
- 在小红书取消收藏后，本地索引不会自动删除对应记录。
- 评论区和图片文字目前不能划线。
- 小红书页面结构变化后，采集与划线选择器可能需要更新。
- `chrome.storage.local` 默认有容量限制；收藏量和 Note 很多时应定期备份。

## 更新

如果使用开发者模式安装：

1. 先导出完整 JSON 备份。
2. 用新版本文件覆盖原扩展文件夹，保持路径不变。
3. 在 `chrome://extensions` 点击扩展卡片上的刷新按钮。
4. 刷新已经打开的小红书页面，使内容脚本更新。

不要为了更新先移除旧扩展，否则本地数据可能丢失。

## 开发

这是一个无构建步骤的 Chrome Manifest V3 扩展：

```text
manifest.json          扩展配置与权限
sidepanel.*            盲盒、Notes 与采集界面
content-script.js      收藏页 DOM 读取与滚动采集
probe-main.js          读取收藏页自身返回的收藏列表响应
annotation-script.js   原笔记正文划线与 Note 浮窗
service-worker.js      后台保存、状态与消息处理
assets/                扩展图标
```

运行基础检查：

```bash
npm run check
```

更完整的手动回归步骤见 [docs/TESTING.md](docs/TESTING.md)，架构与数据流见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
